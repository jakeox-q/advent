Matches Enterprise's collection UI: "Filter" button toggles the sidebar; "Sort by" dropdown; "Compare" toggle (adds a Compare tick box to each card, can be switched off in theme settings); list / grid view icons; applied filters as the first sidebar group with ⓧ chips and "Clear all"; each group collapsible with counts, "Show more" and "Clear". On mobile the button reads "Filter & Sort" and opens Enterprise's drawer with sort, filters and a "Show N results" button. Price uses Enterprise's own price range (inputs + slider); players, play time, complexity and rating reuse that same slider look over the band values.

Sort: Date, new to old (newest preorders first). Mixed-catalogue filters (Dean's open question): Preorders and Just Arrived hold board games and RPGs together. Shopify only shows filter values that exist in the current results, so BGG filters collapse when an RPG-only result set is showing.
